# Bank Management System - C++

A simple, console-based Bank Management System built using **C++** and **Object-Oriented Programming (OOP)** concepts. 
This project allows users to create accounts, deposit, withdraw, check balance, and manage customer data using file handling.

---

## Features

- Create New Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Data Saved using File Handling (`bank.dat`)
- Simple & User-Friendly Console Menu
